# Teach Yourself Electricity & Electronics — Interactive Quiz (Chapters 9–12)

A self-contained, zero-dependency interactive web quiz covering **80 practice questions** across Chapters 9–12 of *Teach Yourself Electricity and Electronics*:

- **Chapter 9:** Alternating Current Basics (20 questions + oscilloscope waveform SVGs)
- **Chapter 10:** Inductance (20 questions + coupled-inductor circuit diagrams)
- **Chapter 11:** Capacitance (20 questions)
- **Chapter 12:** Phase (20 questions + polar vector & phase-quadrature diagrams)

## Features
- **Instant Practice Mode:** Immediate answer verification with step-by-step mathematical and conceptual explanations.
- **Exam Simulation Mode:** Complete full chapter or 80-question assessments before grading against the book's **≥ 18/20 (90%)** mastery target.
- **Custom Inline SVG Diagrams:** Crisp, responsive vector diagrams for Figs. 9-15, 9-16, 9-17, 10-12, 10-13, 12-12, and 12-13.

## Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g., `electricity-electronics-quiz`).
2. Upload `index.html` and `README.md` to the root of the repository (or extract this ZIP archive into your repo).
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, select `main` / `/ (root)`, and click **Save**.
4. Your interactive quiz will be live at `https://<your-username>.github.io/electricity-electronics-quiz/`.
